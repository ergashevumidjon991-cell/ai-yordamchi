# Bilim bazasi

Bu papkaga `.txt` yoki `.md` fayllarni qo'ying: kitob konspektlari, kurs eslatmalari,
YouTube video transkriptlari, o'zingizning qoidalaringiz. Bot maslahat berganda
birinchi navbatda shu materiallarga tayanadi.

Masalan:
- `montaj-qoidalari.md`
- `marketing-hormozi.txt`
- `mening-brendim.md` — kim uchun kontent qilasiz, uslubingiz, narxlaringiz

Fayl qo'shgandan keyin botni qayta ishga tushiring: `systemctl restart ai-yordamchi`.
Juda katta fayllar (yuzlab sahifa) API narxini oshiradi, shuning uchun eng muhim
qismlarini konspekt qilib qo'ygan ma'qul.
